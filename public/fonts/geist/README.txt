Geist and Geist Mono variable WOFF2 subsets (weights 100–900).
These are the unchanged assets from the existing next/font/google build.
CSS unicode ranges and fallback metrics are preserved in app/fonts.css.
Bundled locally so production builds do not depend on Google Fonts downloads.
